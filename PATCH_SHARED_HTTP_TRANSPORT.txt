Change:
A provider may explicitly request X-VUEO-HTTP-Transport: shared in source headers.
PlaybackHttpTraceDataSource.Factory then builds Media3 OkHttpDataSource using the
exact PluginHttp.client instance already used for provider fetches. It preserves
source headers, streaming reads, transfer listeners, redirects, DNS policy and
DataSpec ranges. Master, child playlists, keys and segments use this transport.
The internal marker is removed from default and per-request network headers.
There are no site/domain/provider matching rules, proxy, extra preflight requests
or automatic retry/fallback loops. Unmarked providers retain their existing client.
The selected shared client retains its existing timeouts, including18s call timeout.

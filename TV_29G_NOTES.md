# TV 29G.1 Player UI Correction

Date: 2026-09-06

## Locked UI

- No centre playback controls.
- No on-screen Back or Lock buttons.
- Removed the large boxed bottom control row.
- Bottom UI is now a clean progress bar plus one compact capsule: Subs, Audio, Sources, Episodes.
- Next and More are compact top-right actions.
- Focus highlight appears only on the focused action instead of permanent cards around every action.

## Remote behaviour

- Hidden controls: Left/Right quick seek 10 seconds.
- Hidden controls: OK/Enter toggles Play/Pause without showing centre UI.
- Hidden controls: Down opens the bottom capsule. Up prefers contextual Skip/Next, then top actions.
- Visible controls: D-pad navigates actual focus targets and OK activates the focused item.
- Remote Back closes a panel, then hides controls, then exits the player.
- Hardware media keys remain supported.

Playback, source recovery, resume/history, subtitle, audio and episode logic are unchanged.

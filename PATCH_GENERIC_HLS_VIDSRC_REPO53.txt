Cause verified: HD-2 child playlists reference PNG/WebP-wrapped MPEG-TS media.
The website's HLS loader strips 8-byte PNG or 12-byte RIFF/WEBP prefixes, and
conditionally applies repeated XOR before demuxing. The previous app decoded only
playlists; wrapped segments reached Media3 unchanged.

No provider domains, route IDs, media prefix constants or site XOR keys are embedded
in the VUEO decoder. Provider code supplies the patterns/key using explicit source
instructions. This is a finite set of general byte transformations, not an arbitrary
runtime capable of every future algorithm. Website changes may need provider updates.

Optional source fragment parameters, alongside existing vueo_hls_v1/key/audio:
segment_prefixes: comma-separated hexadecimal patterns; ?? matches any byte.
segment_key: optional repeated-XOR key in hexadecimal, 1–64 bytes.
segment_plain: optional plaintext prefix; matching stripped payload skips XOR.
Matched segment prefixes are stripped. Unmatched segment bodies pass through.
Policies apply only to exact media URLs explicitly referenced by decoded playlists,
including external HTTPS media hosts. AES key and initialization-data URLs do not
inherit segment processing. No automatic domain matching or additional HTTP calls.
Range retries fetch the complete wrapped segment once, transform it, and then expose
the requested decoded offset/length. Segments are buffered up to32MiB per open;
playlists up to2MiB. Maximum4096 exact segment and128 playlist policies per factory.

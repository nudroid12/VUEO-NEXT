# VUEO-NEXT 

Clean VUEO monorepo for Mobile + TV with one shared core.

## Foundation 01

This initial foundation intentionally contains no migrated production feature code. It proves the dependency direction first:

```text
shared/core -> mobile
shared/core -> tv
```

Both apps display a handshake generated by the same shared-core implementation.

## Modules

- `:mobile` - Android Mobile, `com.vueo.app`
- `:tv` - Android TV, `com.vueo.tv`
- `:shared:core` - reusable core

## Build

```bash
./gradlew :mobile:assembleDebug :tv:assembleDebug
```

The old VUEO repository remains the known-good migration reference until parity is reached.

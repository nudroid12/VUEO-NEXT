Changes:
1. Provider-filtered plugin scans have separate cache AND single-flight keys.
   Null (all providers), blank, and named provider filters cannot collide.
2. Ready providers start without waiting for missing scripts elsewhere.
   Missing scripts are repaired on IO per provider before execution slots are
   acquired. Existing execution/WebView concurrency limits remain in force.
3. The central discovery engine receives immutable raw addon snapshots and owns
   cleaning/ranking. Other UnifiedMediaEngine callers retain cleaned results.
4. Cache+fresh merges are reused for status/subtitle-only publications.
   Unchanged plugin source lists no longer remap and invalidate source cleaning.
5. Ranking assesses each candidate once per rank operation while preserving
   score, size, provider-name ordering and stable ties. The general comparator
   remains available to existing callers.
6. Explicit Refresh skips the outer source-session cache and invalidates the
   scoped plugin result cache. Normal cache loading says checking providers,
   since plugin results may themselves still be fresh in cache.
7. Successful empty subtitle responses get at most one late-result retry.
   Failure/timeouts retain the existing overall retry/time budget; nonempty
   responses stop retrying as before, including language-filtered results.

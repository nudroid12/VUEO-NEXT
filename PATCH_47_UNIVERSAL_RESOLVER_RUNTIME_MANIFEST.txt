VUEO NEXT - PATCH 47 UNIVERSAL RESOLVER RUNTIME

Baseline
- Continues from TV 46 resolver runtime on VUEO-NEXT-main (30).
- Provider-neutral compatibility only.
- No provider names, domains, selectors or provider-specific rules.
- No UI, playback presentation, subtitle workspace or motion changes.

Changed runtime files
- shared/core/src/main/java/com/vueo/shared/core/plugin/PluginHttp.kt
- shared/core/src/main/java/com/vueo/shared/core/plugin/PluginRuntime.kt

Universal compatibility
- Fetch Headers, Request and Response objects.
- Response text, JSON, ArrayBuffer, bytes, Blob and clone support.
- Blob, File and FormData with bounded multipart upload support.
- Text, ArrayBuffer, typed-array, Blob and multipart request bodies.
- AbortController, AbortSignal.timeout and native OkHttp request cancellation.
- Standard timeout, interval and clear behaviour.
- Axios request, get, post, put, patch, delete, head and options methods.
- Axios params, paramsSerializer, baseURL, auth, responseType and transforms.
- Axios instances, defaults, interceptors, CancelToken and cancellation errors.
- Compatibility aliases for node-fetch, cross-fetch, undici, form-data and buffer.
- Expanded Buffer helpers for UTF-8, Base64, hex, allocation and concatenation.
- Runtime capability descriptor for safe feature detection.

Safety and performance controls
- Compatibility logic is local and performs heavy conversion only when invoked.
- Request body limit: 4 MiB.
- Response body limit: 4 MiB.
- Request timeout is clamped between 250 ms and 30 seconds when supplied.
- Direct video and audio response bodies are not copied into the Java heap.
- Provider HTTP calls are cancelled when JavaScript aborts or provider execution ends.
- DNS checks apply to redirects and reject local/private destinations.
- HTTPS downgrade redirects remain disabled.

Validation
- Generated JavaScript passed Node ECMAScript module syntax validation.
- Runtime smoke tests passed for multipart, binary response, Axios, Buffer and abort flow.
- Archive integrity and whitespace checks are required before delivery.
- Android build intentionally not run because the local build environment is unavailable.

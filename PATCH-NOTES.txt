APP VUEO-NEXT — Kids age controls (TV + Mobile) and TV avatar focus scroll

Upload this ZIP to the VUEO-NEXT app repository root. Paths overwrite app files directly. Apply on top of the previously supplied app patches. No Worker, SQL migration or workflow/YML changes.

Kids controls:
- Enable Kids Profile, then choose maximum age7,12 or16 in either profile editor.
- Existing Kids profiles default to7. Unsupported stored limits fall back to7.
- kidsMaxAge is part of the existing profile JSON, so existing Account sync carries it with the profile.
- Missing/ambiguous certifications are hidden in Kids profiles. The app does not fetch additional metadata per poster; a provider/feed that supplies no certification can yield empty Kids lists. PG is conservatively treated as10, PG-13 as13, TV-14 as14; mature ratings never pass16.
- Catalogue/search partial and final output, local discovery/search caches, Home featured/recommendation/Trakt rows, entity results, related titles and Library views are filtered.
- Source discovery rejects disallowed titles with a message. Both player entry points reject disallowed/unknown titles before player setup.
- Original library records are retained. Filtering is for views; background Trakt synchronization explicitly reads raw data. Kids-filtered Home results do not replace the general persisted catalogue cache.

PIN behavior:
- Set up a separate four-digit parental PIN on first use, on EACH device. First-time setup must be completed by the parent. This is separate from individual profile unlock PINs.
- Once set, the parental PIN gates saving Kids changes (including disabling Kids or changing the age), choosing an adult profile, deleting profiles when Kids exist, and entering adult/add-profile management from an active Kids profile.
- The first entry into Kids also prompts setup if this device has no parental PIN. Accounts with Kids profiles show the picker at startup.
- Salted PIN hashes stay local and do not sync. Existing profile unlock PIN behavior is retained.
- These are app-level controls based on metadata supplied by content sources, not a guarantee about actual footage or a tamper-proof device control.

TV avatar fix:
- Four-column scrollable panel, circular avatars and1.18x focus retained.
- Focus target coordinates stay fixed; scaling occurs inside the clickable target.
- Scoped reveal policy scrolls only a clipped row, with space for the enlarged avatar, rather than repivoting a visible row on horizontal focus changes.
- Previous profile editor alignment, same-size Delete/Save and Kids icon retained.
